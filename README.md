# HTML File Concatenator

A standalone, single-file web tool that merges five HTML/text files into one downloadable HTML file.

## How to Use

1. **Open** `index.html` in any modern browser — no server required.
2. **Upload** five `.txt` (or `.html`) files, one per slot, in the order you want them concatenated (1st → 5th).
3. Click **Concatenate Files** to merge them.
4. **Preview** the combined output, then click **Download Merged HTML File** to save it.

## Features

- Entirely client-side — no data leaves your browser.
- Drag-and-drop or click-to-upload for each slot.
- Instant preview with file-size and line-count metadata.
- One-click download of the final merged `.html` file.
- Modern, responsive dark-mode UI.
